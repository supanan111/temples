บทที่ 3
การวิเคราะห์และออกแบบระบบ (System Analysis and Design)

ในบทนี้จะนำเสนอรายละเอียดการวิเคราะห์และออกแบบระบบ ThumWadThaiHub (ระบบศูนย์รวมข้อมูลและบริหารจัดการวัดไทยออนไลน์) ซึ่งประกอบไปด้วยการออกแบบสถาปัตยกรรมระบบ (System Architecture), แผนผังกระบวนการทำงานหลัก (System Flowcharts), แผนภาพความสัมพันธ์ของข้อมูล (Entity Relationship Diagram) และพจนานุกรมข้อมูล (Data Dictionary) เพื่อใช้อ้างอิงในการพัฒนาและบำรุงรักษาระบบ

3.1 สถาปัตยกรรมระบบ (System Architecture)

ระบบถูกออกแบบตามสถาปัตยกรรม Multi-tier Web Architecture โดยแบ่งหน้าที่การทำงานออกเป็น 4 ชั้นหลักอย่างชัดเจน เพื่อความยืดหยุ่น ปลอดภัย และรองรับการขยายตัวในอนาคต รองรับการทำงานได้ทั้งบนเซิร์ฟเวอร์แบบ On-Premise/XAMPP, Docker Container (Render) และ Serverless (Vercel)

3.1.1 ส่วนประกอบสำคัญของสถาปัตยกรรม

  • Client Layer: รองรับการเข้าถึงผ่าน Web Browser ทุกแพลตฟอร์ม (Responsive Web Design) รองรับผู้ใช้ 4 กลุ่ม ได้แก่ ผู้เยี่ยมชมทั่วไป, สมาชิก, แอดมินวัด และซูเปอร์แอดมิน
  • Application Layer: พัฒนาด้วยภาษา PHP (เวอร์ชัน 8.2 ขึ้นไป) ใช้แนวทางการจัดการเซสชัน (PHP Session Management) และการเชื่อมต่อฐานข้อมูลผ่าน PHP Data Objects (PDO)
  • Persistence Layer: รองรับฐานข้อมูลแบบ Dual-Driver (MySQL สำหรับ On-Premise / PostgreSQL สำหรับ Cloud Serverless เช่น Neon.tech)
  • Storage Layer: แยกส่วนจัดเก็บไฟล์อัปโหลดอย่างเป็นสัดส่วน โดยมีโฟลเดอร์สำหรับภาพทั่วไปของวัด (`uploads/`) และภาพหลักฐานสลิปการโอนเงิน (`donation_uploads/`)

3.1.2 ตารางกำหนดสิทธิ์การใช้งานระบบ (Role-Based Access Control - RBAC)

บทบาท (Role) สิทธิ์การใช้งาน (Permissions & Capabilities) โมดูล/หน้าจอหลัก
ผู้เยี่ยมชมทั่วไป (Guest) สืบค้นข้อมูลวัดตามจังหวัดและภาค, ดูรายละเอียดกิจกรรมและข่าวสาร, สแกน QR ทำบุญ index.php, temple_page.php, donate.php
สมาชิก (Member / `user`) จองศาลา/อุปกรณ์/นิมนต์พระสงฆ์/แผงงานวัด, อัปโหลดสลิปทำบุญ, ตรวจสอบและยกเลิกคำขอจอง, รับการแจ้งเตือน booking.php, my_bookings.php, check_status.php
ผู้ดูแลวัด (Temple Admin / `admin`) จัดการข้อมูลวัดของตนเอง (`temple_id`), เพิ่ม/แก้ไขทรัพยากรที่เปิดให้จอง, อนุมัติ/ปฏิเสธคำขอจอง, ตรวจสอบสลิปบริจาคเงิน, เพิ่มกิจกรรมและข่าวสาร admin_dashboard.php, manage_bookings.php, manage_donations.php, manage_items.php
ผู้ดูแลระบบหลัก (`superadmin`) จัดการรายชื่อวัดทั้งหมดในระบบ, สร้างและมอบหมายสิทธิ์แอดมินวัด, สลับมุมมองวัด (`switch_temple`), ดูสถิติรวมระดับประเทศ superadmin_dashboard.php, manage_temples.php, manage_users.php
